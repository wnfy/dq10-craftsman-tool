# dq10-craftsman-tool

## 素材価格の保存

- レシピを開き「価格を保存」で、そのレシピの素材単価と職人道具代を保存。
- 素材単価は素材名ごとに全レシピで共有。道具代はレシピごと。
- 未保存の入力は画面内では共有するが、再読み込みすると最後に保存した価格に戻る。
- 素材ごとのリセット、レシピで使用する素材のまとめてリセット、設定から全素材リセットに対応。
- リセットは入力中と保存済みの両方に反映。同じ素材を使うほかのレシピにも反映する。
- 道具代は専用ボタンでリセット。全素材リセットでは道具代・収益記録を消さない。
- 保存先は同一端末・ブラウザの localStorage。端末間同期はなく、ブラウザのサイトデータ削除で保存価格も消える。
- 従来の原価欄の「クリア」は「計算条件クリア」に変更。作成回数・売却額・成果などだけを戻し、価格は専用リセットで操作する。
